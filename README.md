# video-rsi

面向技术创作者的本地视频方案 CLI 规划。当前仓库只有设计与开发计划，**尚未实现可运行程序**。

第一阶段目标：用本人盲选验证标题、封面建议和口播脚本是否更值得制作，同时记录生成费用、耗时和修改成本。默认单轮，多轮通过对照实验决定是否保留。

- [设计规范](DESIGN.md)：目标、Unix CLI 协议、数据合同、恢复和盲选规则。
- [完整开发计划](docs/superpowers/plans/2026-10-09-video-rsi.md)：10 个顺序任务、接口、失败测试、验收与研究门槛。

技术路线：TypeScript + Pi AI，单 npm 包、JSON/JSONL 文件。固定创作流程使用普通函数；有自主工具使用需求时再引入 Pi Agent Core。

Python、官方 RRSI、平台世界模型与自动策略晋升不属于首版。RRSI 保留为有可信评测后再选择的研究路线；项目名称不代表已实现该算法。

本仓库目前没有运行结果、在线模型 smoke 或创作效果验证，不提供爆款保证。
